# Notices

RF-Musette is an independent RackForge plugin implemented in Rust and
distributed under GPL-3.0-only.

RF-Musette and RackForge are separate software components. The plugin package
contains only RF-Musette-owned runtime code, metadata and the license/notice
files included in this repository.

RF-Musette contains no recorded sound. Every sample it produces is computed
from a physical model of free reeds, built from published measurements; the
sources are listed in `docs/SOURCES.md` and `docs/RESEARCH.md`. No sample
library, recording or third-party synthesizer source code was used to build it.
Manufacturer and product names appear in the documentation only to identify
the instruments and documents they refer to; none of those manufacturers has
any connection with this project.
